## 更新

- 渠道编辑与快速导入抽屉改版，拉取模型后可直接筛选和选择。
- 模型测试按模型名自动选择请求协议，并可手动切换。
- 新建渠道与快速导入默认使用固定权重，保持配置行为可预期。
- 重整渠道、日志和设置页面组件；修整 Gojo 主题按钮与状态开关。

## CLI 与 skill

有 Go 1.25+ 时可直接安装 CLI，并安装共享 skill：

```sh
go install github.com/liguangsheng/wildtoken/cmd/wildtokenctl@v0.2.5
wildtokenctl skill install --apply --yes
```

完整变更见 [v0.2.4...v0.2.5](https://github.com/liguangsheng/wildtoken/compare/v0.2.4...v0.2.5)。
