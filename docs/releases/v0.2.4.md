## 升级须知

- 升级前备份数据库和加密密钥。认证 Header 现在也会自动加密存储；回退旧版本需恢复升级前的数据库，不能只替换程序。
- 升级前创建的 Responses ID 没有账户归属记录，查询及 `previous_response_id` 续接会返回 404，需要重新发起请求。

## 新增

- 独立 `wildtokenctl`，提供 58 个 API 命令、JSON/NDJSON 输出和变更预览，支持 Pi/OpenCode 配置合并及共享 skill 安装。
- macOS Intel、Apple Silicon 菜单栏应用，数据与应用资源分开存放，支持错误提示和优雅退出。应用尚未做 Developer ID 签名或 Apple 公证。
- 所有平台包、macOS 应用及 Docker 镜像包含 CLI；控制台支持在途请求筛选和复制渠道凭据。

## 修复

- 封住路径穿越及重定向对代理白名单的绕过，修复 multipart 模型路由和映射。
- 修复渠道详情读取失败后保存会清空 Key、旧请求的 401 清掉新登录令牌的问题。
- 将新 Responses ID 绑定到创建它的令牌、渠道和 Key，避免多账户轮转后查不到响应。

## 安装 CLI 和 skill

有 Go 1.25+，且 Go 安装目录已在 `PATH` 中时：

```sh
go install github.com/liguangsheng/wildtoken/cmd/wildtokenctl@v0.2.4
wildtokenctl skill install --apply --yes
```

没有 Go 时，从对应平台包提取客户端即可。CLI 不依赖服务端程序或网页资源。
详见 [CLI 使用说明](https://github.com/liguangsheng/wildtoken/blob/v0.2.4/docs/cli.md)。
